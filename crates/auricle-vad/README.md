# auricle-vad

Voice activity detection as a hand-written Rust forward pass, no inference runtime: Auricle v1 (foreground-selective, 83k parameters) and, behind a feature, Silero VAD v6

Part of [Auricle](https://github.com/himanshu007-creator/auricle), the listener for voice agents. MIT.

The optional `silero` feature compiles in Silero VAD v6 weights, MIT, Silero Team; their notice is `model/LICENSE.silero`.
